# Zap Books brand files

## Files

| File | Use |
|---|---|
| `zap-books-logo.svg` / `.png` | Full logo on light backgrounds |
| `zap-books-logo-dark.svg` / `.png` | Full logo on a near-black background |
| `zap-books-logo-dark-transparent.svg` | Full logo with white wordmark, for placing on dark surfaces |
| `zap-books-icon.svg` | Icon alone |
| `favicon.svg`, `favicon-16/32/48.png` | Browser tab icons |
| `zap-books-app-icon.svg`, `app-icon-180/192/512.png` | Home-screen and app icons (180 for Apple touch icon, 192/512 for web manifest) |

## Colors

| Name | Hex | Use |
|---|---|---|
| Zap orange | `#FF9F0A` | Logo, highlights. Never as a background for white text. |
| Deep orange | `#D97A00` | Logo back book and spine |
| Action orange | `#B45309` | Buttons and links with white text (meets WCAG AA contrast) |
| Ink | `#1B1F27` | Wordmark, text, dark backgrounds |
| White | `#FFFFFF` | Wordmark on dark, bolt |

## Type

Wordmark: Outfit Bold, converted to outlines (no font needed to display the logo). Outfit is licensed under the SIL Open Font License; see `OFL-Outfit.txt`. The app may use Outfit for headings.

## Rules

- Keep clear space around the logo of at least the bolt's width.
- Don't stretch, recolor, rotate, or add effects.
- Below 48 px, use the icon alone, not the full logo.
